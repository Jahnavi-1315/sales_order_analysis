
# Sales Order Analysis Project

## 1. Project Overview

This project focuses on analysing sales and order
data using SQL, Python and MySQL.

The objective is to extract meaningful business
insights from sales data and understand customer,
product and revenue performance.

## 2. Project Objectives

- Clean and prepare raw datasets using Python.
- Store and manage data using MySQL.
- Retrieve records from MySQL using Python.
- Perform SQL queries for business analysis.
- Calculate sales revenue.
- Analyse customer and product performance.
- Generate reports and visualizations.

## 4. Project Structure

## 4. Project Structure

- datasets/ - Raw datasets
- python_scripts/ - Python analysis scripts
- reports/ - Generated reports
- sql_scripts/ - SQL database scripts
- screenshots/ - Project screenshots and outputs
- README.md - Project documentation
- requirements.txt - Python dependencies

## 5. Database Setup

1. Install MySQL Server and MySQL Workbench.
2. Create a database named sales_analysis.
3. Execute the SQL scripts inside sql_scripts/.
4. Load the required datasets into the database.
5. Configure database credentials locally.

## 6. Python Setup

Install the required Python libraries:

pip install -r requirements.txt

Run the Python scripts from the project directory.
